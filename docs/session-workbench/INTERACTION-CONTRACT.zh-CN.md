# 交互行为契约 v1（2026-08-21）

> 本文档是 Session/Room/页签/工作台交互行为的**唯一规范源**。此后：
> ① 所有 UI 修复以"与本契约的偏差"立项，验收对着契约验；
> ② 新功能先改契约再写代码；
> ③ 契约没定义的行为 = 待拍板，不许工人自行发明。
> 现状标记：✅=已达标 / 🔧O#=已知偏差（对应 DOGFOODING-LOG 条目）/ ❓=待拍板。

## 一、五条铁律

1. **同类实体同等能力**。Session 与 Room 同为"可对话实体"：凡对 Session
   存在的通用动作（打开/聚焦/换工作台/关闭/重命名/删除/搜索可达），Room
   必须有对等物；仅当语义不存在时豁免（如 Room 无 fork、无单一 agent 连接）。
   用户原话（O33）："不是要完全一致，而是相通的功能要都有。"
2. **一个实体一个家**（O34 裁决）。同一 Session/Room 在所有工作台中最多
   一个页签；任何入口"打开"已开实体 = 跨台跳转聚焦既有页签；新窗口/新实例
   只走显式动作。
3. **点击 = 去现场**。任何提及、卡片、搜索结果、徽章的点击都跳转到实体
   现场并聚焦，绝不静默复制实例、绝不落在死文本上（O11 的推广）。
4. **右键 = 该宿主下的全部动作；缺能力灰显而非隐藏**。菜单项因后端能力
   缺失不可用时，灰显+tooltip 说明原因。隐藏让缺口不可见，灰显让缺口
   自我暴露（本条为领导新裁决，适用于 O33 过渡期）。
5. **自明性**。每个面板/设置区块必须能回答"这是什么、作用域多大、写到
   哪里"（O27/O35 一族）；文案写人话，长解释进 tooltip（O31 惯例）。

## 二、实体 × 宿主行为矩阵

### 工作台页签树（右侧竖排）

| 动作 | Session 行 | Room 行 |
|---|---|---|
| 单击 | 激活该页签 ✅ | 激活该页签 ✅ |
| 右键 | 关闭 / 移动到工作台 N / 在新工作台打开 ✅（O17 一刀） | 同左三项 ✅（O33 全通，2026-08-21 领导 CDP 实测换台往返） |
| 拖拽 | 台内排序 + 跨台移动；Shift+拖 = 复制引用 🔧O17 余量 | 同左 🔧O17/O33 |
| 关闭 | 只关页签不动会话 ✅ | 同左 ✅ |

### 侧边栏（分类树 / 聊天区）

| 动作 | Session | Room |
|---|---|---|
| 单击 | 按铁律 2：已开→聚焦；未开→当前台开页签 🔧O34（现状可跨台重复开） | 同左 🔧O34 |
| 归属显示 | 按 Path/Collection 归桶 ✅ | 同左 ✅（O15 已修） |
| 徽标 | 未读=蓝点；收到未回/失败=红点；数字=计数 | 同左（事实源同一套后端计数，禁止另算） |

### 会话中心

| 动作 | Session 行 | Room 行 |
|---|---|---|
| 行结构 | 标题/徽标/时间/动作按钮 ✅ | 与 Session 行同构（差异仅"群聊"标识与成员数）✅（O19 已修，领导实测：徽标全套/Collection/所在工作台/folder/占位对齐） |
| 点击 | 聚焦既有页签或打开 🔧O34 | 同左 🔧O34 |
| 过滤分段 | 未读/收到未回/发出未回/失败，措辞带方向+tooltip ✅（O31 前半） | 同左 ✅ |
| 回复进度 | @N 人的帖子显示 N/M 已回 🔧O31 后半 | 同左 🔧O31 后半 |

### 搜索（Ctrl+K）与消息卡片

- 搜索结果点击 = 铁律 3 跳转聚焦；结果类型自带说明 ✅（O27）。
- 会话里的 Room 消息卡：显示群聊标题、点击直达 Room 页签 ✅（O11）；
  Room 里的会话提及芯片：点击直达该 Session（发帖者本人不可点自己）✅。
- 工具调用不内联渲染进 Room 时间线；活动摘要走活动桥 ✅裁决（O24，桥排队）。

### 工作状态可见性（O34 第三层）

- 页签圆点：运行中（脉冲点=prompting）与需注意（红=error）两态，事实源=
  连接快照（按 tab id 索引 + conv-{folder}-{agent}-{id} 回退）。✅（O34 已合；
  忙态像素级验证待有真实在跑回合时补）
- 工作台级："N 个在忙"徽标挂树的工作台行头。✅（O34 已合）
- 会话中心：默认按最近活动排序兜底"最近工作过"。🔧（O34 尾巴，与 O19 同文件
  错峰后补）
- Room 行成员活动聚合：另记后续任务。❓
